隐私邮箱外部取件 API v2

本服务提供两种取件方式：只读 IMAPS，以及返回验证码历史的 HTTP API。所有响应均可重复读取，不消费验证码，也不改变邮件已读状态。

验证码 API

使用完整 API Key：

curl -H "Authorization: Bearer API_KEY" https://HOST/api/v1/otp

或直接访问签发的取码 URL：

https://HOST/api/v1/otp?token=DERIVED_TOKEN

默认响应是最新优先的裸 JSON 数组，每个邮箱最多保留 100 条验证码：

[{"otp":"876543","time":"2026-08-11T12:00:00+08:00"},{"otp":"123456","time":"2026-08-11T11:00:00+08:00"}]

设置 ICLOUD_API_OTP_RETURN_LATEST_ONLY=true 后，有记录时只返回该数组第一项的裸 JSON 对象，也就是真正最新的有效 OTP。旧变量 ICLOUD_API_OTP_RETURN_LAST_ONLY 保留为兼容别名；同时设置时以正式变量为准。这两种 JSON 模式没有验证码时都返回 200 []。

还可以用 format 参数改变输出形态。查询串只接受 token、format 与 message；message 只能与 format=html 同时出现。多余参数、重复参数或无法解析的查询串一律按凭证无效拒绝：

https://HOST/api/v1/otp?token=DERIVED_TOKEN&format=plain
https://HOST/api/v1/otp?token=DERIVED_TOKEN&format=html
https://HOST/api/v1/otp?token=DERIVED_TOKEN&format=html&message=MESSAGE_ID

format=plain 的响应体就是最新验证码本身，Content-Type 为 text/plain。format=html 返回该隐私邮箱的归档邮件列表，最新优先、最多 100 封，包括没有提取到验证码的邮件；没有归档邮件时返回 200 与零字节响应体。

format=html&message=ID 返回单封邮件阅读页：用 token 打开时，顶部是发件人、主题、时间与「返回列表」，正文放在沙箱 iframe 中。发信人提供的 HTML 按原字节渲染，所以图片和按钮都能正常加载与点击；只有纯文本时，把文本转义后以等宽块显示。邮件正文已被清理或校验失败，或 message 不属于当前隐私邮箱时，返回 404 MAIL_CONTENT_UNAVAILABLE，不会静默降级成空白页。正文以 ICLOUD_API_MAX_BODY_BYTES（默认 512 KiB）为上限，超出的部分会被截断。

阅读页渲染的是不可信的第三方邮件内容，该响应保留 script-src 'self' 与 base-uri 'self'，只放宽 img-src 以允许外链图片，并把 form-action 收紧为 'none'。正文额外放在不带 allow-scripts 的沙箱 iframe 中，邮件 CSS 也不会影响返回栏。注意放开外链图片意味着发信人可以通过图片 URL 得知你何时打开了阅读页。

验证码从邮件主题、纯文本和 HTML 可读文本中提取，支持连续的 6 位 ASCII 数字及 Grok 使用的三位数字加连字符再加三位数字（如 610-313），返回时保留连字符。候选不能与字母或数字相邻，也不会从更长的连字符分组号码中截取片段；升级前保存的其他格式历史值也不会出现在 OTP API 响应中。

访问令牌

用服务签发的 client ID 与 refresh token 换取一小时有效的 IMAPS XOAUTH2 访问令牌：

curl -X POST https://HOST/oauth2/v2.0/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  --data-urlencode "grant_type=refresh_token" \
  --data-urlencode "client_id=CLIENT_ID" \
  --data-urlencode "refresh_token=REFRESH_TOKEN"
{"access_token":"ACCESS_TOKEN","token_type":"Bearer","expires_in":3600}

只读 IMAPS

连接部署方提供的 IMAPS 主机与端口，用户名为隐私邮箱地址。可直接使用服务签发的 IMAP 密码登录，也可使用上一步访问令牌进行 XOAUTH2 登录。

邮箱仅包含一个只读 INBOX，支持 LIST、STATUS、SELECT/EXAMINE、SEARCH、FETCH、UID FETCH 与 IDLE。写入、改旗标、移动和删除命令会返回只读错误。

API Key、IMAP 密码、client ID、refresh token 与 access token 都由本服务签发；轮换邮箱凭证后，旧凭证会同时失效。
